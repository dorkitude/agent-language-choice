Implemented encounter creation in `src/main.rs`.

- `POST /v1/play/campaigns/{id}/encounters`
- Owner-only DM authorization
- Returns the specified `201` encounter JSON
- Returns `409` for duplicate IDs or a campaign already in combat
- Persists encounters in SQLite without changing exploration turns
- Reset clears encounter state

Verification: `cargo test` passed (33 tests). `run.sh` remains executable and starts the server in the foreground.
