Implemented DM tools in `app.py`:

- `POST /v1/dm/encounter-builder` with stored campaign/monster lookup and adjusted-XP calculations.
- `POST /v1/dm/loot-parcel` with deterministic tier-1 loot.
- `POST /v1/dm/session-recap` based on campaign events.
