Implemented rest exploration turns in `app.py`.

- Added `POST /v1/play/campaigns/<id>/turn/rest`
- Validates `short` / `long`, active-player turn ownership, and event sequencing
- Long rests restore the acting character to `hp_max`
- Rest passes control to the DM and returns the specified event payload
- Added persistent member HP defaults (`20 / 20`) with migration support
