Implemented campaign-document support in `app.py`.

- `PUT /v1/play/campaigns/{id}/document` is owner-only and persists `story` plus `dm_notes`.
- Owner GET receives both fields.
- Campaign players GET receive only `story`; `dm_notes` is never included.
- Player PUT returns 403.
- Document storage is included in database initialization and reset.

Verified with isolated Flask test-client requests using the workspace dependency path. `run.sh` remains executable and ready; no server was started.
