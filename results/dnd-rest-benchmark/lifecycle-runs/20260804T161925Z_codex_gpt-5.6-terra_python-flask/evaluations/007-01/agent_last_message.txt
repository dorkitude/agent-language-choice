Implemented SQLite-backed campaign state APIs in `app.py`:

- `POST /v1/campaigns`
- `POST /v1/campaigns/<id>/characters`
- `POST /v1/campaigns/<id>/events`
- `GET /v1/campaigns/<id>/state`

Campaign data is durable, reset by `/v1/storage/reset`, validates malformed input, and returns `404`/`409` where appropriate. Existing API behavior remains intact.

Verified with Flask test-client checks, compilation, shell syntax, and diff validation. `run.sh` is ready and starts the server on `127.0.0.1:$PORT` in the foreground.
