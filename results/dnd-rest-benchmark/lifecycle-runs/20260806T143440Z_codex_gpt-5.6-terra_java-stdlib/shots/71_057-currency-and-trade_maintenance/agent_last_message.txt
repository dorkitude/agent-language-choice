Implemented consumable inventory support in `Main.java`.

- Added bodyless `POST .../inventory/items/{item_id}/consume`.
- Only owners may consume.
- Only `healing-potion` is accepted.
- Consumption removes one stack unit, persists it, omits zero stacks from inventory, and returns the specified healing effect.
- Invalid/non-consumable items return 400; absent/empty stacks return 409.

`run.sh` remains executable and foreground-starts the server. Verified with `javac Main.java`; the server was not started.
