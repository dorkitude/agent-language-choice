Implemented GM narration in `Main.java`.

- `POST /v1/play/campaigns/{id}/narrations` returns `201` with ordered narration events.
- Only the campaign-owning DM may narrate; players receive `403`.
- Per-campaign sequences start at `1`, append only, and persist across reloads.
- Storage reset also clears narrations.
- `run.sh` remains executable and foreground-starts the server on `127.0.0.1` using `PORT`.

Verified with OpenJDK 26.0.1: `javac Main.java` succeeds. I did not start the server.
