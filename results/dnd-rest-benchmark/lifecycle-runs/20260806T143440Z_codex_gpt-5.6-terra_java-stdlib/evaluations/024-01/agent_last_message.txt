Implemented `GET /v1/play/campaigns/{id}/my-turn`.

It:
- Requires an authenticated player who belongs to the campaign.
- Returns `is_my_turn`, `current_actor`, the caller’s `{id,name}` character, and public narration `recent_events`.
- Excludes other characters, class data, queue data, and DM-private fields.
- Preserves the existing `/turn` endpoint unchanged.

Verified with `javac Main.java`; `run.sh` remains executable and foreground-ready. I did not start the server.
