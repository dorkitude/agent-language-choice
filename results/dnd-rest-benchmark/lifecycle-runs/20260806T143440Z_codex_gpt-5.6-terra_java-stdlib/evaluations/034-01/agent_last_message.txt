Implemented Rest Turns in `Main.java`.

- Added `POST /v1/play/campaigns/{id}/turn/rest`
- Supports `short` and `long`; invalid type returns 400
- Enforces active-player turn ownership (409 otherwise)
- Long rests restore the player to deterministic 20/20 HP
- Rest events advance turn to the DM and participate in future turn rotation
- Added durable HP storage with a safe SQLite migration for existing databases
- Updated codebase guide

Verified with `javac Main.java`. `run.sh` remains foreground, loopback-bound, and PORT-driven.
