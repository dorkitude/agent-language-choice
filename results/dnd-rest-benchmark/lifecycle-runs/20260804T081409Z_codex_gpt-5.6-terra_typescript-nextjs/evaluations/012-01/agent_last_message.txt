Implemented NPC/faction support with persistent SQLite storage:

- `POST /v1/campaigns/{id}/factions`
- `POST /v1/campaigns/{id}/npcs`
- `GET /v1/campaigns/{id}/relationships`

NPCs require an existing faction in the same campaign; relationship summaries count NPCs with positive disposition as friendly. Storage reset now clears the new tables.

Verified with `./node_modules/.bin/tsc --noEmit`. `run.sh` remains executable and ready; I did not start the server.
