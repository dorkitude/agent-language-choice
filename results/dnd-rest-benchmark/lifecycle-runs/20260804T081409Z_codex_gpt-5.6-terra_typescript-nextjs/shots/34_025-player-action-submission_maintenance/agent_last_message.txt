Implemented `POST /v1/play/campaigns/{id}/actions`.

- Active player action returns `201` with action event fields and `next_actor: "dm"`.
- Waiting players and the DM receive `409`.
- Action type is persisted with the event; existing databases migrate safely.
- Turn/context reads reflect the DM as current actor after an action.

Verified with `./node_modules/.bin/tsc --noEmit`. `run.sh` remains executable and ready; no server was started.
