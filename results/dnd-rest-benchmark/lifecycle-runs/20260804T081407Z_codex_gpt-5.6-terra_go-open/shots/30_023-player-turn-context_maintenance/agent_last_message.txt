Implemented `GET /v1/play/campaigns/{id}/my-turn`.

It now:
- Requires an authenticated `player` who is a campaign member.
- Returns `is_my_turn`, `current_actor`, only the caller’s `{id,name}` character, and ordered public narration events.
- Rejects DMs and non-members with `403`; unauthenticated requests get `401`.
- Includes focused privacy/authorization coverage in tests.

Verified with `GOCACHE="$PWD/.gocache" go test ./...`. `run.sh` remains executable and starts the server in the foreground.
