Implemented the SQLite-backed monster and item compendium APIs.

- Added create/read routes for monsters and items.
- Monster tags persist in order and are returned on reads.
- Duplicate slugs return `409`; invalid input returns non-2xx.
- Storage reset clears compendium records too.
- Added round-trip regression coverage.

Verified with `go test ./...`, `go vet ./...`, and `bash -n run.sh`. `run.sh` is executable and starts the foreground server on `127.0.0.1:$PORT`. No server was started.
