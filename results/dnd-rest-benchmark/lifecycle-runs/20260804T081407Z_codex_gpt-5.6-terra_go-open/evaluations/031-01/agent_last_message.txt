Implemented Scene State with durable SQLite storage and routes for create, enter, close, and current-scene reads.

- Owner-only scene mutations; members can read the current open scene.
- Duplicate scene IDs return 409; closed scenes cannot be entered.
- Closing the current scene causes current-scene reads to return 404.
- Storage reset clears scene state.
- Added lifecycle coverage in `main_test.go`.

Verified with:

```sh
GOCACHE="$PWD/.gocache" go test ./...
GOCACHE="$PWD/.gocache" go vet ./...
```

`./run.sh` remains executable and starts the foreground server on `127.0.0.1:$PORT`.
