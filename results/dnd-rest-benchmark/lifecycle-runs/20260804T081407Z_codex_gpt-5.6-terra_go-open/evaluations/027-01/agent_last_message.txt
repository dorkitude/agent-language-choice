Implemented GM resolution support.

- Added `POST /v1/play/campaigns/{id}/resolutions`.
- Only the active campaign owner can resolve; player attempts return `409`.
- Resolution events persist with shared event sequencing.
- Resolution advances to the next player and increments `turn_number`.
- Turn state is migrated durably for existing SQLite databases.
- Added coverage for the owner/player handoff.

Verified with `GOCACHE="$PWD/.gocache" go test ./...`. `run.sh` remains executable and ready.
