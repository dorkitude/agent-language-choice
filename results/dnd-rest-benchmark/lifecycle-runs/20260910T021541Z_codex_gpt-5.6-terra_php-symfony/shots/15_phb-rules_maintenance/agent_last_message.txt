Implemented the PHB rules endpoints in `index.php`:

- `POST /v1/phb/spell-slots`
- `POST /v1/phb/rests/long`
- `POST /v1/phb/equipment-load`

They return deterministic JSON and reject invalid/unsupported requests with 400 responses. Existing `run.sh` remains executable and starts the server in the foreground on `127.0.0.1:$PORT`.

Verified with `php -l index.php` and `bash -n run.sh`.
