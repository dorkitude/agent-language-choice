Implemented `GET /v1/play/campaigns/{id}/my-turn`.

It enforces player membership and returns only:

- `is_my_turn`
- `current_actor`
- caller-owned `character` `{id,name}`
- public narration `recent_events`

DMs and non-members receive 403; unauthenticated requests retain 401 behavior. No private character or DM-only fields are exposed.

Verified `index.php` and `storage.php` syntax. `run.sh` remains executable, foreground, `PORT`-based, and bound to `127.0.0.1`. The server was not started.
