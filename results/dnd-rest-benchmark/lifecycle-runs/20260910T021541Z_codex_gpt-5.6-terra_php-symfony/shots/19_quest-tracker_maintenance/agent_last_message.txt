Implemented quest tracking with persistent SQLite storage:

- `POST /v1/campaigns/{id}/quests`
- `POST /v1/campaigns/{id}/quests/{quest_id}/progress`
- `GET /v1/campaigns/{id}/quests/summary`

Added strict validation, campaign/quest not-found handling, duplicate-ID conflicts, idempotent milestone completion, and reset support.

Validated with `php -l` for both PHP files, schema initialization, and `bash -n run.sh`. `run.sh` remains executable and foreground-serves on `127.0.0.1:$PORT`. No server was started.
