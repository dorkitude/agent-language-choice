Implemented `POST /v1/play/campaigns/:id/start`.

It now:

- Allows only the campaign-owning DM.
- Requires at least two party members.
- Activates the lobby once, starting with the first joined player.
- Returns the required turn payload.
- Returns 403 for players and 409 for active or under-populated campaigns.

`run.sh` remains ready and unchanged. Verified with `ruby -c app.rb` and `bash -n run.sh`; no server was started.
