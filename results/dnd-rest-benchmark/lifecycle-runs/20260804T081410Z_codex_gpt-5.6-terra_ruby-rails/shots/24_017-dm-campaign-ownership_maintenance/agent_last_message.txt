Implemented DM-owned play campaign creation at `POST /v1/play/campaigns`.

- Requires `Authorization: Bearer session-<username>`.
- Returns 401 for missing/invalid registered users; 403 for authenticated non-DMs.
- DM creation returns the specified lobby campaign payload with HTTP 201.
- Play campaigns persist separately from legacy campaigns and reject duplicate IDs with 409.
- Updated reset handling for the new table.
- Verified Ruby syntax and `run.sh` remains ready to serve on `127.0.0.1:$PORT`.
