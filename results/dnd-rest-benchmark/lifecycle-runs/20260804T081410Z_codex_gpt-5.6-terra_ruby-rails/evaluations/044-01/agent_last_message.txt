Implemented encounter rewards and closing in `app.rb`.

- Owner-only `POST .../rewards` persists one reward record per encounter; duplicate awards return 409.
- Owner-only `POST .../close` closes the encounter and returns `xp_awarded` (0 if none).
- Reward storage resets with the existing SQLite reset flow.
- `run.sh` remains executable and foreground-bound to `127.0.0.1:$PORT`.
