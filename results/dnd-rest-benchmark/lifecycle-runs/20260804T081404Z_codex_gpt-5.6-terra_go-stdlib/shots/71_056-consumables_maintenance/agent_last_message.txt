Implemented consumable inventory support in `main.go`.

- Added owner-only `POST .../inventory/items/{item_id}/consume`.
- Only `healing-potion` is consumable; other or unknown IDs return 400.
- Consuming decrements one unit, deletes an empty stack, and returns the required healing effect payload.
- `run.sh` remains executable and starts the foreground server on `127.0.0.1:$PORT`.

Verified with `gofmt`, `go test ./...`, and `go build ./...`. The server was not started.
