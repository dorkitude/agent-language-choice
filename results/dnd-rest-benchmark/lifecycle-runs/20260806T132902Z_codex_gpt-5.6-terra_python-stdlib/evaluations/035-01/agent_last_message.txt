Implemented encounter creation in `server.py`.

- `POST /v1/play/campaigns/{id}/encounters` is owner/DM-only.
- Returns the specified 201 encounter payload.
- Duplicate encounter IDs and campaigns already in combat return 409.
- Starting combat changes campaign status to `combat`, preserving the exploration queue without advancing it.
- Encounter storage participates in reset.
