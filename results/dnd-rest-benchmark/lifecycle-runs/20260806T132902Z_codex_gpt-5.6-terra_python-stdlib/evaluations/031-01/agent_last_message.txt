Implemented scene state in `server.py` with durable SQLite storage:

- Owner-only create, enter, and close scene endpoints
- Member/owner current-scene read endpoint
- Closed scenes cannot be entered; closing the active scene clears it
- Scene tables are included in initialization and storage reset
- `run.sh` remains executable and foreground-starts the server on `127.0.0.1:$PORT`

Verified with `python3 -m py_compile server.py` and isolated SQLite behavior checks. The server was not started.
