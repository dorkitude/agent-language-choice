Implemented party/combatant binding in the Django API.

- `POST .../combatants` binds a party member with initiative and returns 201.
- Duplicate bindings return 409; missing/non-party members return 400.
- `DELETE .../combatants/{member}` unbinds and returns `{"removed": member}`.
- Owner/DM authorization and existing campaign/encounter checks are preserved.
- Added durable SQLite storage for bound combatants.
- Verified with Django system checks and request-level smoke tests.

`run.sh` remains executable and starts Django on `127.0.0.1:$PORT` in the foreground. No server was started.
