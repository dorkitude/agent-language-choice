Implemented Player Action Submission.

- Added `POST /v1/play/campaigns/{id}/actions`.
- Active players append atomic action events and hand the turn to the DM.
- Response includes required sequence, actor, type, text, and `next_actor`.
- Waiting players and DMs receive 409.
- Action sequences share the campaign’s narration sequence.
- `run.sh` remains executable and foreground-ready.

Verified with Django request checks, `manage.py check`, Python compilation, and `bash -n run.sh`. No server was started.
