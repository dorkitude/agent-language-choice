Implemented `GET /v1/play/campaigns/{id}/gm/status`.

- Owner-only; player requests return 403.
- Returns `needs_attention`, `current_actor`, ordered party summaries, and up to five recent narration events.
- Returns 401 unauthenticated, 404 unknown campaign, and 409 before activation.
- `run.sh` remains executable and uses `PORT` on `127.0.0.1`.

Verified with `manage.py check` and an end-to-end Django client scenario.
