Implemented the spellbook route in `dndsite/urls.py`.

- `POST .../spells`: owner-only, validates payload/class, returns 201; duplicates return 409.
- `GET .../spells`: returns ordered spellbook to campaign members.
- Rogue spell additions return 400; non-owners return 403.

Verified with isolated Django requests plus `manage.py check`, compilation, and `bash -n run.sh`. `run.sh` remains ready to start on `127.0.0.1:$PORT`.
