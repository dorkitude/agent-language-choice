Implemented audit and export APIs.

- `GET /v1/campaigns/{id}/audit`
- `GET /v1/campaigns/{id}/export`

Both return deterministic JSON, enforce GET, and return the existing 404 JSON response for unknown campaigns. `inventory_items` counts positive inventory records.

Verified with isolated Django request checks, `manage.py check`, compilation, and `bash -n run.sh`. `run.sh` is ready and no server was started.
