Implemented encounter creation in `index.php`.

- Owner-only `POST /v1/play/campaigns/{id}/encounters`
- Returns the specified 201 encounter payload
- Persists encounter IDs; duplicates return 409
- Marks the campaign `combat`, pausing existing exploration-turn endpoints without changing their queue/events
- Storage reset includes the new table
- Verified with `php -l index.php` and `bash -n run.sh`

`run.sh` remains executable and starts Slim on `127.0.0.1:$PORT` in the foreground.
