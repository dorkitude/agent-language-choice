Implemented analytics reporting in `index.php`:

- `GET /v1/campaigns/{id}/analytics/summary`
- `POST /v1/campaigns/{id}/analytics/risk-report`

Both aggregate persisted campaign state deterministically, validate invalid risk-report payloads, and return JSON errors for unknown campaigns. `./run.sh` remains executable and binds to `127.0.0.1:$PORT` in the foreground.

Verified with `php -l index.php`. I did not start the server.
