Implemented GM narration in `app.rb`.

- Owner-only `POST /v1/play/campaigns/:id/narrations`
- Returns ordered `{sequence, kind:"narration", actor:"dm", text}` with 201
- Player requests receive 403
- Sequences are per-campaign, start at 1, and append atomically
- Narrations reset with storage reset
- `run.sh` remains executable and ready

Verified syntax and the endpoint behavior in an isolated in-process test; no server was started.
