Implemented level progression in `app.rb`.

- Added owner-only `POST .../level-up`
- Enforces exactly one next level and returns 400 for invalid/missing level
- Persists class, CON modifier, level, and max HP from character builds
- Applies hit-die + CON HP growth and returns hit dice/proficiency
- Keeps character health maximum synchronized
- Preserves `run.sh` foreground loopback behavior

Verified with `bundle exec ruby -c app.rb` and `bash -n run.sh`. Server was not started.
